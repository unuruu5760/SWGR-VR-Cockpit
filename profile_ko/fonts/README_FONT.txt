Copy C:\Windows\Fonts\malgun.ttf (Malgun Gothic) into this folder.
UEVR loads menu fonts only from the profile's fonts folder; without it the Korean menu text shows as "?".
(The font is part of Windows and is not redistributed here.)

C:\Windows\Fonts\malgun.ttf (맑은 고딕)를 이 폴더에 복사하세요.
UEVR 메뉴는 프로필의 fonts 폴더에 있는 글꼴만 읽어요. 없으면 메뉴의 한글이 ? 로 나와요.
(윈도우에 들어 있는 글꼴이라 여기에는 넣지 않았어요.)
