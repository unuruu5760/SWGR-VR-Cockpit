# 스타워즈 갤럭틱 레이서 — UEVR VR 콕핏 (v2.0.0)

**STAR WARS Galactic Racer**용 UEVR 프로필과 Lua 스크립트 하나예요. 모든 차량에서 조종석에
앉혀 주고, 드디어 콕핏이 움직여요: 엔진·노면 진동, 부스터 돌진, 기수 들림, 쿵 하는 착지,
원하는 만큼만 기우는 기울기, 점프 때 조종사 몸을 따라가는 시점. 전부 게임 안에서 조절할 수
있고, 바꾼 값은 지금 타는 차량에 자동으로 저장돼요.

> English: [README.md](README.md)

## 왜 만들었냐면

VR 콕핏 시점에서 차가 미동도 안 했어요. 엔진 떨림도, 노면 느낌도, 부스터를 켤 때 밀려나는
느낌도 없어서 엄청난 속도로 달려도 세워 둔 차에 앉아 있는 것 같았고, 속도감을 거의 못 느꼈어요.
그래서 콕핏이 살아 있고 속도가 느껴지도록 이 효과와 기능들을 만들었어요.

선택용 **pak 모드**는 다른 목적이에요. 게임 UI의 검은 띠, 장면 전환 검은 화면, 어둡거나 하얀
반투명 판은 모니터에선 괜찮은데 VR에서는 눈앞에 커다란 판처럼 떠 있어서 너무 보기 싫어요.
그걸 없애 줘요.

## v2.0.0에서 새로 생긴 것

원래 콕핏은 조종석에 앉혀 줬어요. v2.0.0은 그 콕핏(좌석 고정, 시점 따라가기, 게임 카메라)을
그대로 두고, **스크립트 하나**(`swgr_vr_cockpit.lua`, 한국어판·영어판)에 이것들을 더했어요.

- **콕핏 흔들림** — 머리가 스프링에 달린 것처럼 움직여요: 공회전·W 부릉, 주행 중 엔진, 노면
  진동과 출렁임, 코너 쏠림, 드리프트 떨림, 슬립스트림 흔들림, 충돌. 간단한 세기 다섯 개 +
  세부 조절에 값 하나하나.
- **부스터 손맛** — 애프터버너·램젯·레이스 출발 때 툭 튀어나가는 돌진, 기수 들림, 켜진 동안
  웅웅, 램젯 과열될수록 커지는 흔들림.
- **부스터 연출** — 부스터 동안 색이 진해지고 가장자리가 어두워지고 번쩍; 램젯 점화·출발 순간
  아주 잠깐 멈칫(**순간 멈칫**)과 세상 크기가 출렁(**세상 출렁**).
- **착지** — 아래로 눌렸다 올라오고, 땅에 닿는 순간 **쿵**, 그리고 보는 각도를 툭 꺾어서
  내 머리가 충격을 받은 느낌의 **머리 충격**.
- **기울기 제한** — 바이크·비행기형은 드리프트 때 90도까지 기울어요. 그중 얼마만큼 눈에
  전해질지 정해요 (차량별).
- **점프 때 몸 따라가기** — 공중에서 조종사가 몸을 일으키면 눈이 그 가슴을 따라가서 몸통
  속에 박히지 않아요. **차량 + 캐릭터별**로 저장돼요 (캐릭터마다 체격이 달라서).
- **눈앞 가까운 것 안 그리기** — 눈 바로 앞의 조종사 몸통 안쪽을 그리지 않아요. 착지로 눌릴 땐
  더 넓게.
- **레이스 시작** — 시동 장면을 보고 나서 시점이 부드럽게 날아 좌석으로 들어가요. 게임
  카메라에서는 차체가 엔진에 맞춰 부르르 떨어요.
- **메뉴 화면 위치** — VR 시점이 맵 밑이나 벽 속에 가는 메뉴·결과 화면에 위치를 고정해요
  (자주 나오는 화면은 들어 있고, 직접 저장도 돼요).
- **차량별 자동 저장** — 차를 타고 바꾼 값은 그 차에만 저장되고, 안 만진 값은 기본값을
  따라가요. 차종별 내장 기본값, 11대의 눈 위치, 캐릭터별 몸 따라가기가 들어 있어요.
- **단축키** — 키보드는 누른 키로 바로 지정(UEVR 키 지정 방식), 컨트롤러는 Back + 버튼 조합.
- **비교 스위치 하나** — "추가 기능 켜기"를 끄면 더한 기능이 전부 꺼져서 원본 v1.2.0과 똑같이
  동작해요.
- **한글 / 영어 메뉴**, 모든 항목에 설명, 세부 조절은 주제별로 정리.
- **선택: pak 모드** (따로 받기) — VR에서 깨져 보이는 검은 띠와 어둡거나 하얀 반투명 판을
  없애요.

전체 목록: [CHANGELOG.md](CHANGELOG.md)

## 설치

### 필요한 것

- STAR WARS Galactic Racer (PC)
- **joeyhodge의 갤럭틱 레이서 백엔드**(`100726swgrp2`)가 들어간 UEVR — v1.2.0 콕핏 때 쓰던
  그 UEVR이에요. UEVR과 게임은 여기에 들어 있지 않아요.

### 1. 프로필 (추천)

[Releases](../../releases)에서 **`SWGR-VR-Cockpit-v2.0.0-KO.zip`**(영어 메뉴는 `-EN.zip`)을
받으세요.

1. 게임을 끄고 지금 프로필을 **백업**하세요: `%APPDATA%\UnrealVRMod\SWGR-Win64-Shipping\`
2. 둘 중 하나:
   - zip 이름을 **`SWGR-Win64-Shipping.zip`**으로 바꾸고 UEVR의 **Import Config**로 가져오기
     (UEVR은 zip 파일 이름으로 프로필 폴더를 정해요), 또는
   - zip 안의 내용을 `%APPDATA%\UnrealVRMod\SWGR-Win64-Shipping\`에 그대로 풀기.
3. 프로필의 `scripts` 폴더에서 예전 카메라 스크립트를 지우세요: `swgr_cockpit_camera.lua`,
   `swgr_stable_camera.lua` 같은 `swgr_cockpit_*.lua`. 같이 돌면 서로 싸워요 (남아 있으면
   메뉴에 경고가 떠요).
4. **한글 메뉴:** `C:\Windows\Fonts\malgun.ttf`(맑은 고딕)를 프로필의 `fonts` 폴더에 복사하세요.
   UEVR 메뉴는 그 폴더의 글꼴만 읽어요. 없으면 한글이 `?`로 나와요.
   (윈도우에 들어 있는 글꼴이라 배포 파일에는 넣지 않았어요.)
5. 게임을 켜고 UEVR을 주입하세요. 스크립트는 알아서 돌아가고, 메뉴는
   **UEVR 메뉴(Insert) → Script UI → 스타워즈 갤럭틱 레이서 VR**에 있어요.

프로필에는 v1.2.0 프로필의 UEVR 설정·`user_script.txt`·cvars(Nero의 화면 어긋남 수정 포함)와
스크립트가 들어 있어요.

### 2. 스크립트만

이미 잘 되는 프로필이 있으면 **`swgr_vr_cockpit-v2.0.0-KO.lua`**(또는 `-EN.lua`)만 받아서
프로필의 `scripts` 폴더에 넣고, 예전 콕핏 스크립트를 지우세요 (위 3번). Nero의 화면 어긋남
수정은 [알아둘 점](#알아둘-점)을 보세요.

### 3. pak 모드 (선택)

**`SWGR-NoBlackBars-pak-v2.0.0.zip`**: VR에서 보기 싫은 검은 띠와 판을 없애요. 바로 아래
[pak 모드](#pak-모드)를 보세요.

### v1.2.0에서 올라올 때

v2.0.0은 `swgr_cockpit_camera.lua`를 대신해요. 설정은 따로 저장하고

## pak 모드

**왜:** 게임 UI는 검은 띠(레터박스), 장면 사이 검은 화면, 메뉴 뒤의 어둡거나 하얀 반투명 판을
써요. 모니터에선 평범한데 VR에서는 눈앞에 커다란 검은 판·흰 판처럼 떠 있어서 너무 보기 싫어요.
이 모드는 그걸 투명하게 만들어서 필요한 부분만 보이게 해요.

**바꾸는 것** (UI 위젯 몇 개만, 다른 건 안 건드려요):

- 출발·결승 검은 띠, 장면 전환 검은 화면, 출발 전 어두운 판 두 개, ESC 일시정지 판 → 투명
- 레이스 결과창과 결과창 일시정지의 하얀 반투명 배경 → 투명
- 레이스 실패("리그 토큰 분실") 화면의 어두운 배경 → 원래의 40%
- 메인 메뉴 로그인 확인의 반투명 판 → 투명

**알아둘 점**

- 스크립트·프로필과는 따로예요. 같이 써도, 이것만 써도, 안 써도 돼요. 없어도 콕핏은 잘 돌아가요.
- 설치: `SWGR-NoBlackBars-pak-v2.0.0.zip`을 게임 폴더에 풀어서 `zzz_SWGR_NoBlackBars_P.pak`,
  `.ucas`, `.utoc` 3개가 `STAR WARS Galactic Racer\Griffin\Content\Paks\~mods\`에 들어가게 하세요.
  게임 원래 pak 파일은 건드리지 않아요.
- 지우기: 그 3개만 지우면 돼요.
- 2026년 10월 버전 게임에 맞춰 만들었어요. 게임 업데이트로 그 화면들이 바뀌어서 이상해 보이면
  빼 주세요.

## 조작

| 키 (기본) | 동작 |
| --- | --- |
| **F3** | VR 콕핏 ↔ 게임 카메라 (3인칭 / 보닛) |
| **F4** | 다음 게임 카메라 (먼저 게임 카메라로 바꿔요) |
| **F5** | 추가 기능 켜기/끄기 — 원본 콕핏과 비교 |
| *(없음)* | 머리 위치를 좌석에 맞추기 — 원하면 키를 지정하세요 |

**단축키** 메뉴에서 바꿔요: 키보드 버튼을 클릭하고 원하는 키를 누르세요 (Esc = 취소, Insert는
UEVR 메뉴 키라 못 써요). 동작마다 컨트롤러 조합도 정할 수 있어요: **Back(뷰)**를 누른 채
A / B / X / Y / 방향키 / RB. 키를 정하는 동안엔 단축키가 작동하지 않고, 다른 동작이 쓰던 키를
누르면 이쪽으로 옮겨져요.

게임 카메라 상태에서는 게임 원래의 카메라 바꾸기 버튼도 그대로 돼요.

## 메뉴

**UEVR 메뉴 → Script UI → 스타워즈 갤럭틱 레이서 VR**. 어떤 항목이든 마우스를 올리면 설명이
나와요. 위에서부터:

| 묶음 | 들어 있는 것 |
| --- | --- |
| *(맨 위)* | **추가 기능 켜기**, 시점(VR 콕핏 / 게임 카메라), 단축키 안내, **머리 위치를 좌석에 맞추기**, 지금 타는 차량과 캐릭터 |
| **시점·눈 위치** | 눈 위치(좌우·앞뒤·위아래), 시점 따라가기, **기울기 %**, 조종사 보이기, 레이스 소개 장면, 충돌할 때 바깥 카메라, **점프 때 조종사 몸 따라가기**(위로·앞으로), **눈앞 가까운 것 안 그리기**(안 그리는 거리) |
| **흔들림** | 켜기, 세기 다섯 개 %(엔진, 노면, 쏠림, 부스터 손맛, 착지·충돌), **착지 때 머리 충격** |
| **부스터 연출** | 화면 색감·섬광 %, 순간 멈칫, 세상 출렁 |
| **레이스 시작** | 시동 장면 보고 콕핏으로 이동, 차체 엔진 떨림 % |
| **세부 조절 (고급)** | 값 하나하나, 주제별: 엔진 · 노면·코너 · 부스터 돌진·기수 들림 · 부스터 화면·순간 멈칫·세상 출렁 · **착지·충돌** · 시점(기울기) · 흔들림 전체(머리 스프링) · 레이스 시작 |
| **저장된 차량** | 값이 있는 차량 전부. 차를 안 타도 고칠 수 있어요. |
| **단축키** | 키보드 키와 컨트롤러 조합 |
| **메뉴 화면 위치** | VR 시점이 엉뚱한 곳에 가는 메뉴 화면 고치기 |
| **전체 설정 초기화** | 공용 설정을 기본값으로 (두 번 눌러야 해요). 저장된 차량은 남아요. |

% 값은 **100 = 추천값, 0 = 끔, 200 = 두 배**예요.

## 차량별 설정과 자동 저장

차마다 느낌이 다르고 좌석 위치도 달라서, 콕핏 설정은 거의 전부 **차량별**로 따로 가져가요.
"저장" 버튼을 누를 필요는 없어요.

**동작 방식**

- **차를 타고 있는 동안** 차량 관련 값을 바꾸면 그 값은 **그 차량에만 바로 저장**돼요. 눈 위치,
  기울기, 몸 따라가기, 안 그리는 거리, 흔들림 세기, 세부 조절 값이 다 해당돼요. 메뉴에는
  **`[이 차량]`**으로 표시돼요.
- **안 만진 값은 저장하지 않아요.** 그 차는 계속 기본값을 따라가요. 그래서 나중에 기본값이
  바뀌면 그 차에도 그대로 반영돼요.
- 차량이 쓰는 값은 이 순서로 정해져요 (먼저 있는 것을 써요):
  1. **내가** 그 차량에 저장한 값
  2. 그 차량의 **내장** 값 (눈 위치)
  3. 그 **차종의 내장** 값 (바이크 / 자동차 / 스키머 / 비행기형)
  4. 공용 값
  5. 추천값
- **점프 때 몸 따라가기**는 한 단계 더 나눠서 **차량 + 캐릭터**별로 저장돼요
  (`[차량·캐릭터]` 표시). 캐릭터마다 체격과 자세가 달라서예요. 따로 맞추지 않은 캐릭터는
  그 차량 값을 써요.
- `[이 차량]` 값 옆의 **기본값으로** 버튼은 그 값 하나만 지워요.
- **차에 안 탔을 때**(메뉴 화면)는 차량 관련 슬라이더가 회색으로 기본값만 보여 주고 바뀌지
  않아요. 차에 타서 바꾸세요. 공용 설정(시점 따라가기, 조종사 보이기, 켜기/끄기, 단축키 등)은
  언제든 바꿀 수 있어요.
- **저장된 차량**에는 값이 있는 차량이 다 나와요. 차량을 열면 그 차를 안 타도 고칠 수 있어요:
  눈 위치, 기울기, 몸 따라가기, 안 그리는 거리, 흔들림 다섯 개, **고급 옵션**(세부 조절 전체,
  접혀 있음), **캐릭터별 몸 따라가기**(접혀 있음, 캐릭터마다 하나씩, "이 캐릭터 값 지우기" 포함).
  - **눈 위치·몸 따라가기 빼고 전부 기본값으로**: 나머지를 지워요.
  - **이 차량에 저장한 것 전부 지우기**: 눈 위치까지 전부 지워요.

## 기능 자세히

### 콕핏 (v1.2.0에서 그대로)

눈은 차량의 `PilotSeat` 소켓에 붙어 있고, 매 프레임 실제로 그려지는 차 모델에서 다시 읽어서
보이는 좌석과 어긋나지 않아요. **시점 따라가기**로 시점이 차를 얼마나 따라 돌지 골라요:

| 선택 | |
| --- | --- |
| 수평 고정 | 방향만 따라가요. 가장 편해요. |
| 언덕만 따라가기 *(기본)* | 오르막·점프의 앞뒤 기울기만 부드럽게 따라가요 (±45도까지). 좌우 기울기는 수평. |
| 차를 부드럽게 따라가기 | 앞뒤·방향·좌우를 0.15초 쿼터니언 필터로. |
| 차를 거의 그대로 따라가기 | 같은 방식, 0.07초. |
| 차체 그대로 | 차 자세 그대로. 멀미 주의. |

레이스 소개 장면과 충돌 카메라는 게임에 맡길 수 있고(콕핏이 잠시 빠지고 조종사를 되돌려
놔요), 게임의 3인칭·어깨 너머·보닛 카메라도 키 하나로 바꿀 수 있어요.

### 기울기

시점의 좌우 기울기 = `기울기% × 최대 × tanh(차 기울기 × 비율 / 최대)`. 100%면 맞춰 둔 만큼
(비율 0.65, 부드러운 최대 50.92도), 50%면 어디서나 절반, 0이면 항상 수평이에요.

### 콕핏 흔들림

모든 움직임은 감쇠 스프링에 달린 위치(와 앞뒤 각도)라서 — "스프링에 달린 머리" — 자연스럽게
시작하고 가라앉아요. 일시정지 중이나 결승 뒤 AI가 운전할 땐 사라져요. 묶음: 엔진(공회전, W 부릉,
주행), 노면(속도 따라 커지는 잔진동, 출렁임), 쏠림(가속, 코너, 드리프트, 슬립스트림),
부스터(애프터버너, 램젯, 출발, 에너지 브레이크, 기수 들림, 저음 웅웅, 과열 흔들림), 착지·충돌.

**부스터 돌진**은 툭 튀어나갔다가 살짝 되튕기고 서서히 돌아와요. "돌진 최대 거리"가 얼마나
나갈지 정해요 (기본 12.5cm). 더 크게 하려면 올리고, 계기판이 너무 가까워지면 낮추세요.

### 착지

공중에선 시점이 살짝 올라갔다가(공중 시점 올리기) 착지와 함께 내려오고, 착지가 시점을 아래로
눌러요 (오래 날수록 깊게, "착지 때 최대 깊이"보다 깊이는 안 내려가요). 눌릴 때 앞으로도 숙여서
조종사 몸통을 피하고, 따로 단단한 스프링으로 땅에 닿는 순간 **쿵**을 줘요. **착지 때 머리
충격**은 보는 각도를 툭 꺾어요(아래로 숙였다 튕기고 좌우로 살짝). VR에서는 시점 *위치*를
움직이면 차가 움직인 것처럼, *각도*를 움직이면 내 머리가 움직인 것처럼 느껴지기 때문이에요.

### 점프 때 몸 따라가기

바이크는 공중에서 조종사가 몸을 일으켜요. 공중에 있는 동안 눈이 조종사 가슴 뼈(`spine_05`)를
좌석 기준으로 따라가요. "위로"·"앞으로" 배율로 조절해요 (0 = 안 따라감, 1 = 가슴만큼, 최대 3).
착지하면 원래 자리로 돌아와요.

### 눈앞 가까운 것 안 그리기

조종사 모델은 손과 한 덩어리라 손을 남기고 몸통만 숨길 수가 없어요. 그래서 콕핏일 때 화면의
가장 가까운 그리기 거리(`r.SetNearClipPlane`)를 "안 그리는 거리"만큼 밀어요 (콕핏이 아닐 땐
원래대로). 앞으로 돌진할 땐 계기판이 안 잘리게 그만큼 당기고, 착지로 눌릴 땐 더 밀어요.

### 부스터 연출

매 프레임 게임 카메라의 후처리에 채도·비네트·짧은 섬광을 부스터 종류별로 넣고, 끝나면
서서히 돌려놔요. 필요한 렌더러 설정(`r.Tonemapper.Quality`, 색수차)은 효과가 보이는 동안만
켜고 끝나면 되돌려요. 순간 멈칫은 게임 전체 시간 배율을 써요 (항상 원래대로 복구). 세상
출렁은 UEVR 월드 스케일을 바꿔요 (+ = 세상이 잠깐 작아지며 멀어짐, − = 확 다가옴).

### 레이스 시작

시동 장면 동안 콕핏은 기다렸다가, 시동이 걸리고 잠시 뒤 게임 카메라에서 좌석까지 부드럽게
날아 들어가요. 조종사 머리는 도착할 때 숨겨요. 게임 카메라에서는 차체(`CustomisationRoot`)가
엔진에 맞춰 떨고, W를 밟으면 더 떨어요.

### 메뉴 화면 위치

어떤 메뉴·결과 화면은 게임 카메라를 그려지는 곳과 먼 데 둬요. 그런 화면엔 저장된 UEVR 카메라
오프셋을 자동으로 적용해요 (메인 메뉴, 멀티플레이 메뉴, 투어 시작·로그, 모든 맵의 결과창, 시동
장면). 다른 화면이 이상하면 **UEVR → Camera → Camera Offset**으로 맞추고 이 메뉴의 **저장**을
누르세요. 레이스 중에는 쓰지 않아요.

## 알아둘 점

- **UEVR의 "Decoupled Pitch"는 꺼져 있어야 해요** (프로필엔 꺼져 있어요). 켜져 있으면 UEVR이
  스크립트 다음에 시점을 수평으로 만들어 버려서 기울기·언덕 따라가기·기수 들림이 안 되고
  HUD만 움직여요. UEVR 카메라 프리셋(Load Camera 0/1/2)이 이걸 다시 켤 수 있어요. 시점이 안
  기울면 이것부터 확인하세요.
- **HDR / 화면 어긋남 설정.** Nero의 `user_script.txt`는 시작할 때 `r.AllowHDR 0`,
  `r.HDR.EnableHDROutput 0`을 `r.SSR.Quality 0`, `r.AmbientOcclusionLevels 0`,
  `r.LensFlareQuality 0`, `r.SSGI.LeakFreeReprojection 0`과 함께 설정하고, `cvars_standard.txt` /
  `cvars_data.txt`에서 `Renderer_r.DefaultFeature.AmbientOcclusion=1`과
  `Engine_r.AmbientOcclusionLevels=1` 줄을 뺐어요. v1.2.0 노트는 HDR을 실행 중에 바꾸면
  세상이 검게 되고 UI만 보일 수 있다고 경고해요. 그렇게 되면 `user_script.txt`에서 HDR 두 줄을
  지우고 `Engine.ini` 방식을 쓰세요:
  `%LOCALAPPDATA%\StarWarsGalacticRacer\Saved\Config\Windows\Engine.ini`를 만들어서

  ```ini
  [SystemSettings]
  r.AllowHDR=0
  r.HDR.EnableHDROutput=0
  ```

  를 넣고 **읽기 전용**으로 해 두세요 (게임이 관리하지 않는 설정 파일을 지워버려요).
- **모든 차량·캐릭터를 시험하진 못했어요.** [차량별 설정](#차량별-설정과-자동-저장)의 안내를
  보세요.
- 한국어판과 영어판은 메뉴 언어만 다르고 값은 같아요.

## 소스에서 빌드하기

```
src/            스크립트 (부분별: _header, 00_core … 90_menu, _footer)
profile/        UEVR 프로필 파일 (config, cameras, cvars, user_script, v1.x 검증 노트)
tests/          run_tests.py + mock.lua: 가짜 게임에서 스크립트 시험
build.py        dist/EN|KO/swgr_vr_cockpit.lua 빌드, "release"는 배포 파일까지
```

- `python build.py` → `dist/EN/swgr_vr_cockpit.lua`, `dist/KO/swgr_vr_cockpit.lua`.
  `src/NN_*.lua` 하나하나를 `do … end`로 감싸요.
- `python build.py release [PAK_폴더]` → `release/`에 프로필 zip 두 개, 스크립트 단독 파일,
  (`PAK_폴더`가 있으면) pak 모드 zip.
- `python tests/run_tests.py dist/KO/swgr_vr_cockpit.lua - next`로 가짜 게임에서 스크립트를
  돌려요: 메뉴(모든 위젯 클릭, ID 중복·트리/폭/비활성 짝·설명에 `%` 없는지), 시동 장면, 모든
  부스터·착지·드리프트·충돌이 있는 레이스, 일시정지, 카메라 전환, 단축키, 차량 교체, 스크립트
  리셋. LuaJIT의 `lua51.dll`이 같은 폴더에 있어야 해요 (들어 있지 않아요. 예: OBS Studio에 있는 것).
  LuaJIT은 Lua 5.1이라 스크립트는 5.3 이상 연산자를 쓰지 않아요.

**값을 새로 추가할 때** — 쓰는 곳에서 `V.tunable(묶음, 키, 추천값, 최소, 최대, 영어, 한국어,
영어설명, 한국어설명)`로 등록하고 `V.val(키)`로 읽어요 (지금 차량의 값, 없으면 기본값).
`90_menu.lua`의 `TUNE_LAYOUT`에 키를 넣어 맞는 주제에 보이게 하세요 (안 넣으면 "기타"에 나와요).
설명은 메뉴를 처음 보는 사람 기준으로: 어떻게 느껴지는지, 언제 올리고 내리는지, 0이면 어떻게
되는지.
